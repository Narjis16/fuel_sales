Fuel Sales Dashboard

 Overview
Interactive dashboard analyzing fuel sales (Petrol & Diesel) across Karachi, Lahore, and Islamabad.

  Tools Used
Power BI Desktop - Interactive visualizations
Python (Pandas) - Data cleaning and preprocessing
GitHub - Project portfolio

Dashboard Features
Sales trends over time (Line Chart)
Sales by region (Bar Chart)
Product share comparison (Pie Chart)
Monthly sales breakdown (Column Chart)
Revenue & Profit Cards

Files in This Repository
   File         |        Description

 data_cleaning.py | Python script for data preprocessing .
